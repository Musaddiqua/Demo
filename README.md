## 📌 Overview

This repository contains **Artificial Intelligence and Machine Learning (AI/ML) Lab Programs** implemented in **Python** as part of academic lab coursework. The programs cover fundamental to intermediate AI & ML concepts, focusing on both **theoretical understanding** and **practical implementation**.

The repository is designed to help:

* Engineering students 🧑‍🎓
* Beginners in AI & ML
* Python learners exploring intelligent systems

## 🧠 Topics Covered

### 🔹 Artificial Intelligence

* Problem Solving using AI concepts
* Search Techniques (BFS, DFS, A*)
* Game Playing (Minimax, Alpha-Beta Pruning)
* Knowledge Representation
* Logic & Inference
* Constraint Satisfaction Problems

### 🔹 Machine Learning

* Introduction to Machine Learning
* Supervised Learning
* Unsupervised Learning
* Regression Algorithms
